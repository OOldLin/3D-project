# 实施与验证状态

本次已将项目升级为专业解剖观察工作台，保留根目录离线 HTML 和 `web/` 独立资源网页两种形式。

## 已完成的代码与资源

- 从官方取得 84 个 OBJ，并与独立镜像的 LFS 指针逐项比较 SHA-256。
- 由实际几何生成 32 个可选择展示组、137,552 个三角面。
- 保留原 4.0 GLB 及原始来源清单，没有删除旧模型。
- 新模型加入 11 个静态瓣叶、5 个乳头肌、四肺静脉组及截短的下腔静脉近心段。
- 加入中英文、缩写和源编号检索；独立显示、隐藏、聚焦、透明度、两套材质和画质选项。
- 加入三方向与斜向网格剖切，切面可移动和反转；剖切与拆分互斥，不自动补成组织。
- 保留拆分与精确复原，增加标签引线和人体方向指示。
- 加入观察记录本地保存、JSON 导入导出和模型版本校验。
- 加入高清 PNG 导出，图内保留来源、许可、显示状态和医学复核状态。
- 专业观察默认静态；简化跳动只由用户手动开启。

## 自动检查结果

结果保存在 `verification-report.json`。检查包括源文件哈希、模型几何、结构映射、截断边界、拆分复原、剖切半空间、36 组方向与宽度取景、检索、显示状态、记录恢复及非法输入拒绝、离线资源一致性和页面元素对应。

这些检查是数学、数据和代码检查，不代表实际浏览器操作已经通过。
