# 心脏三维交互 · 独立参数建模版

双击 index.html 或 start.bat 使用，无需联网。旧版仍保留在相邻 heart-3d 文件夹。
该模型从参数曲面与手工控制点生成，未导入第三方心脏网格或贴图。

## 操作

拖动旋转，滚轮缩放。可检索、选择、隐藏、单独查看结构，进行拆分或表面剖切。
开启“隐藏腔壁看内部”查看瓣叶、乳头肌和腱索。选中内部结构时自动隐藏腔壁。
腔体包络默认隐藏，仅在选中或拆分时展示。记录与旧版按模型哈希隔离。

## 编辑与重建

Node.js 24，执行 npm ci 安装依赖。
node scripts/generate-model.mjs：生成 GLB、结构目录与模型清单。
node build.mjs：生成单文件 index.html 和独立资源 web/。
node verify.mjs：检查几何、结构目录、拆分、取景、剖切和页面打包。
assets/original/heart-original.glb 可导入 Blender 继续雕刻；参数修改应优先保存到生成器。
所有尺寸均为任意展示单位，不能作为毫米、容积或壁厚测量。

## 医学状态与局限

当前为独立参数几何原型，尚未完成医学专家审核，不能当作医学成品销售。
心室自由壁、间隔、心房、心耳、瓣膜、乳头肌、腱索、肉柱和血管均采用简化形态。
大血管与心房接入口采用相交曲面，尚未全部布尔贯通。腱索数量、走向与附着简化。
瓣叶静态，心室长短轴未标定；冠状动脉不完整；不提供患者特异性或血流模拟。
浏览器工具启动失败，真实浏览器的交互、材质和下载行为尚待验收。
docs/geometry-preview.png 为离线几何投影，不能代替网页截图或医学审查。
